Confidentialité

Dernière mise à jour : 15 octobre 2026.

En bref

Cap Stage est un outil gratuit de suivi de candidatures de stage. Il n’a pas de serveur : l’auteur du site ne reçoit, ne voit et ne conserve aucune de vos données.

Ce que vous saisissez

Des candidatures (entreprises, offres, contacts, notes, documents envoyés) et des fiches de projets. Ces informations restent les vôtres.

Où elles sont enregistrées

  • Dans votre navigateur, sur votre appareil, dans le stockage local du site. C’est le cas dès que vous utilisez l’outil.
  • Dans un dossier de votre ordinateur, uniquement si vous activez la sauvegarde automatique dans un dossier (Chrome, Edge) et en choisissez un. L’outil n’accède qu’à ce dossier.
  • Dans un fichier d’export, uniquement si vous cliquez sur Exporter.

Le verrouillage par mot de passe (facultatif) chiffre ces données dans votre navigateur (AES-256-GCM). Le mot de passe n’est jamais enregistré : si vous l’oubliez, les données sont irrécupérables.

Google Drive (si vous activez la synchronisation)

Quand vous cliquez sur « Se connecter avec Google », le site demande trois autorisations : drive.appdata, openid et profile. La première donne accès à un espace caché propre à cette application dans votre Google Drive. Les deux autres permettent de lire votre prénom et un identifiant de compte, uniquement pour vous saluer et pour éviter que deux personnes qui partagent un appareil voient leurs données mélangées ; ils restent dans votre navigateur. Le site ne peut lire, modifier ni lister aucun de vos autres fichiers. Vos données y sont enregistrées dans un fichier cap-stage.json (ou cap-stage.chiffre.json si vous avez activé le verrouillage par mot de passe, auquel cas elles sont chiffrées avant l’envoi et Google ne peut pas les lire).

L’auteur du site n’a aucun accès à cet espace : les échanges se font directement entre votre navigateur et Google. Ces données sont soumises aux conditions et à la politique de confidentialité de Google.

Pour couper l’accès, utilisez « Déconnecter » dans Réglages, ou retirez l’application dans les autorisations de votre compte Google. « Tout effacer » supprime aussi le fichier de votre Drive si vous êtes connecté à ce moment-là.

Aucun suivi

Pas de cookies, pas de statistiques, pas de publicité, pas de traceurs. La page est servie avec une politique de sécurité qui limite ce qu’elle peut contacter. Deux services tiers voient tout de même votre adresse IP, comme pour tout site : GitHub Pages (qui héberge le site) et Google Fonts (qui fournit les polices).

Supprimer vos données

« Tout effacer » dans Réglages supprime vos fiches de ce navigateur, du dossier de sauvegarde automatique et, si vous êtes connecté, de Google Drive. Vider les données du site dans votre navigateur a le même effet sur le navigateur.
